# Teórica 04

**Dá un ejemplo de greedy correcto y uno incorrecto para el mismo tipo de problema.**

El par clásico es la **mochila**. En la **mochila fraccionaria** (los objetos se pueden partir), el greedy por densidad valor/peso es **óptimo**: se llena con el mejor "precio por kilo" y, si el último no entra entero, se lleva la fracción — el argumento de intercambio funciona porque cualquier gramo de un objeto peor puede reemplazarse por uno mejor.

En la **mochila 0/1** (cada objeto entero o nada), el MISMO greedy falla: puede convenir dejar afuera el objeto más denso para que entren dos que juntos valen más. Ejemplo: capacidad 5, objetos (peso 4, valor 5, densidad 1.25) y dos de (peso 3, valor 4, densidad 1.33)... o el del apunte: la densidad no captura el problema de "encajar" enteros. Por eso la 0/1 se resuelve con programación dinámica. Otro par de la unidad: el vuelto (greedy correcto con sistemas canónicos, incorrecto con {1, 3, 4}).
