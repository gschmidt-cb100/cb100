# Teórica 04

**¿Qué es `null`? ¿Cuándo se produce una `NullPointerException` y qué aporta `Optional`?**

`null` es una referencia que no apunta a ningún objeto. La `NullPointerException` ocurre al usar un método o campo sobre una referencia `null`. `Optional` expresa explícitamente "puede no haber valor" y obliga a manejar el caso vacío (`orElse`, `ifPresent`), evitando `null` sueltos.
