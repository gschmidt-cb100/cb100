# Teórica 08

**¿Diferencia entre una excepción que extiende `RuntimeException` y una que extiende `Exception`?**

Las que extienden `RuntimeException` son **no chequeadas**: no obligan a declararlas ni capturarlas; se usan para errores de programación o uso indebido. Las que extienden `Exception` (y no `RuntimeException`) son **chequeadas**: el compilador obliga a declararlas o capturarlas; se usan para condiciones esperables que quien llama debería manejar (por ejemplo, un archivo que no existe).
