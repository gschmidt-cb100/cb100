# Teórica 07

**Si un método muta un objeto recibido por parámetro, ¿se ve afuera? ¿Y si reasigna el parámetro? ¿Por qué?**

Java pasa **por valor**: el método recibe una copia de la referencia. **Mutar** el objeto (ej. `arr[0]=99`) **sí** se ve afuera, porque ambas referencias apuntan al mismo objeto. **Reasignar** el parámetro (ej. `arr = new int[]{...}`) **no** se ve afuera, porque solo cambia la copia local de la referencia.
