# Teórica 06

**¿Qué es el factor de equilibrio y qué exige el AVL?**

El **factor de equilibrio** de un nodo es $FE = altura(subárbol\ izquierdo) - altura(subárbol\ derecho)$ (con altura de árbol vacío $= -1$). Mide hacia dónde y cuánto se "inclina" el nodo: positivo = cargado a la izquierda, negativo = a la derecha, 0 = perfecto.

El AVL exige que **todos** los nodos tengan $FE \in \{-1, 0, +1\}$: se tolera una inclinación de un nivel (pedir 0 exacto sería imposible para la mayoría de los tamaños), pero nunca dos. Tras cada inserción o borrado, los nodos del camino de vuelta a la raíz revisan su factor; si alguno queda en $\pm 2$, se repara ahí mismo con una rotación (simple o doble). Con esa regla se demuestra que la altura es siempre $O(\log n)$ — a lo sumo ~1.44 veces la óptima.
