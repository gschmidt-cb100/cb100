# Teórica 03

**¿En qué se diferencia una referencia de Java de un puntero de C?**

Una referencia lleva hasta un objeto, pero **no** expone su dirección de memoria, **no** permite aritmética de punteros y **no** se puede fabricar a partir de un número. Solo sirve para acceder al objeto (o ser `null`). Esto elimina toda una familia de errores típicos de C.
