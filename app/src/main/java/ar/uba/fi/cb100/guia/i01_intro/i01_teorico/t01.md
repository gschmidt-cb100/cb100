# Teórica 01

**¿Qué es el bytecode y por qué permite "Write Once, Run Anywhere"?**

El bytecode es el código intermedio (`.class`) que produce el compilador `javac`. No son instrucciones de un procesador real, sino de la **JVM**. Como cada sistema operativo tiene su propia JVM capaz de ejecutar ese mismo bytecode, el programa corre igual en todos lados sin recompilarlo: se escribe una vez y se ejecuta en cualquier plataforma.
