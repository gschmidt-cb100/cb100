# Teórica 02

**¿Por qué agregar al final de un vector es O(1) amortizado? ¿Y si agrandáramos de a uno?**

Porque al llenarse se **duplica** la capacidad: las copias a lo largo de n inserciones suman 1+2+4+…+n ≈ 2n = O(n) en total, o sea O(1) por inserción en promedio. Si agrandáramos de a uno, cada inserción copiaría todo: O(n) por inserción, O(n²) en total.
