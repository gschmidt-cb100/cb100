# Teórica 01

**¿Qué se guarda en el stack y qué en el heap? Dá un ejemplo de cada uno.**

El **stack** guarda las variables locales y las llamadas a métodos, y se libera solo cuando cada método termina (ej.: `int a = 5;`). El **heap** guarda los objetos creados con `new` —la memoria dinámica que administra el recolector de basura— (ej.: `new int[]{1,2,3}`).
