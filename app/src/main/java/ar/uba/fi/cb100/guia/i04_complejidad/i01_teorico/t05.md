# Teórica 05

**Resolvé T(n) = 2T(n/2) + n con el método de expansión.**

Expandiendo: T(n)=2T(n/2)+n = 4T(n/4)+2n = 8T(n/8)+3n = … = 2ᵏ·T(n/2ᵏ)+k·n. La recursión termina cuando n/2ᵏ=1, o sea k=log₂n. Entonces T(n)=n·T(1)+n·log₂n = **Θ(n log n)**. (En cada nivel el trabajo suma n, y hay log₂n niveles.)
