# Teórica 08

**¿Por qué la medición empírica del tiempo puede ser engañosa?**

Porque la afectan el compilador JIT (acelera el código "en caliente"), el sistema operativo, el hardware y otras tareas. Mide el comportamiento de UNA corrida en UNA máquina, no el crecimiento del algoritmo; por eso, para comparar algoritmos, la teoría es más confiable.
