# Teórica 10

**¿Qué es la integración continua y qué ingredientes de la materia la habilitan?**

La **integración continua** (CI) es la práctica de que, ante cada cambio subido al repositorio, un servidor **compile y corra todos los tests automáticamente**, avisando si algo se rompió. Los ingredientes ya están en la materia: **Git** (repositorio), **Gradle** (build) y **JUnit** (tests); falta automatizarlos (p. ej. con GitHub Actions).
