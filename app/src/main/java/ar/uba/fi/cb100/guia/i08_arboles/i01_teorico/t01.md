# Teórica 01

**¿Qué diferencia hay entre un árbol binario cualquiera y un ABB?**

El árbol **binario** sólo impone una restricción de **forma**: cada nodo tiene a lo sumo dos hijos (izquierdo y derecho). El **árbol binario de búsqueda** agrega una restricción de **contenido**: en cada nodo, **todo** el subárbol izquierdo contiene valores menores y **todo** el derecho valores mayores — y esto vale recursivamente en cada subárbol. Es esa propiedad (no la forma) la que habilita la búsqueda con descarte: comparar con un nodo permite ignorar medio árbol. Un árbol binario sin el invariante no ofrece ninguna garantía para buscar.
