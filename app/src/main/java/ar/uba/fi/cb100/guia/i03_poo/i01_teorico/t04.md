# Teórica 04

**Explicá los tres pilares: encapsulamiento, herencia y polimorfismo.**

**Encapsulamiento**: ocultar el estado (campos privados) detrás de métodos que protegen los invariantes. **Herencia**: una clase reutiliza y especializa a otra (`extends`), modelando "es un/una". **Polimorfismo**: una referencia del tipo padre ejecuta el método del objeto real (despacho dinámico), lo que hace al código extensible.
