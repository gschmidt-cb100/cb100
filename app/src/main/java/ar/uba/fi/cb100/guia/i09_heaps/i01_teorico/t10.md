# Teórica 10

**¿Cómo se logra un max-heap con `PriorityQueue` y cómo un desempate FIFO?**

**Max-heap**: `PriorityQueue` es min-heap respecto de su comparador, así que basta invertirlo: `new PriorityQueue<>(Comparator.reverseOrder())` — o, para un campo, `Comparator.comparingInt(X::valor).reversed()`. Ahora `poll()` entrega el mayor.

**Desempate FIFO**: `PriorityQueue` **no es estable** — entre elementos empatados, el orden de salida es indefinido. Para que los empatados salgan por orden de llegada hay que hacer el desempate **parte de la prioridad**: asignar a cada elemento un número de secuencia creciente al encolarlo y componer el comparador: `Comparator.comparingInt(X::prioridad).thenComparingLong(X::secuencia)`. Es exactamente lo que hace el triage del integrador (`SalaDeEmergencias`) con `numeroDeLlegada`.
