# Teórica 04

**¿Por qué el in-orden de un ABB entrega los valores ordenados?**

Por inducción sobre el invariante. El in-orden visita: primero **todo** el subárbol izquierdo, después el nodo, después **todo** el derecho. En un ABB, el subárbol izquierdo contiene exactamente los valores menores que el nodo, y el derecho los mayores. Si (hipótesis inductiva) cada subárbol se lista ordenado, entonces la secuencia queda: [menores, ordenados] + [nodo] + [mayores, ordenados] — que es el orden total. Como los subárboles de un nodo hoja trivialmente salen ordenados (vacíos), la propiedad vale para todo el árbol.

Consecuencia práctica doble: un ABB "ordena gratis" (insertar todo y recorrer in-orden), y el in-orden es el test estándar para verificar que un árbol realmente es un ABB.
