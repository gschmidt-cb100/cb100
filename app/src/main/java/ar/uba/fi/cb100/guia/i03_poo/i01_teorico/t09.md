# Teórica 09

**Nombrá tres prácticas que hacen un código más mantenible y explicá por qué.**

Por ejemplo: **nombres claros** (el código se lee más de lo que se escribe), **responsabilidad única** (cada clase/método hace una cosa, así es fácil de cambiar) y **encapsulamiento + validación** (estado protegido e invariantes explícitos, lo que evita estados inválidos). Sumar **tests** da una red de seguridad ante cambios.
