# Teórica 03

**Explicá el encadenamiento. ¿Qué representa el factor de carga α en esta estrategia?**

En el **encadenamiento** (*separate chaining*), cada celda de la tabla no guarda un solo par sino una **lista enlazada** de pares (su "balde" o cadena). Las claves que colisionan simplemente conviven encadenadas en la misma celda. Buscar consiste en: calcular el índice con el hash ($O(1)$) y recorrer **sólo la cadena de ese balde** comparando con `equals`.

El **factor de carga** $\alpha = n/m$ (elementos sobre celdas) es exactamente el **largo promedio de cada cadena**. Si $\alpha$ se mantiene acotado (por ejemplo $\le 0.75$, con rehash), las cadenas son cortísimas en promedio y todas las operaciones cuestan $O(1)$ promedio.
