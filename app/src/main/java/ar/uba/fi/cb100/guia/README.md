# Guía de ejercicios (todos los cuatrimestres)

Paquete base `ar.uba.fi.cb100.guia`. Los temas llevan prefijo de ítem (`i01_…`)
para quedar ordenados. Por cada tema (`i01_intro`, `i02_memoria`, …):

- `i01_teorico/` — teóricas resueltas (`tNN.md`).
- `i02_facil.eNN`, `i03_medio.eNN`, `i04_dificil.eNN` — un paquete por ejercicio (impl+main+test).

Correr: `./gradlew test`.
