# Teórica 09

**¿Qué complejidad tiene el Fibonacci recursivo ingenuo y por qué? ¿Cómo mejorarla?**

O(2ⁿ): recalcula los mismos valores una y otra vez (T(n)=T(n−1)+T(n−2)+O(1)). Se mejora a **O(n)** con una versión iterativa (o memoización), o incluso a **O(log n)** por exponenciación de matrices / fast doubling.
