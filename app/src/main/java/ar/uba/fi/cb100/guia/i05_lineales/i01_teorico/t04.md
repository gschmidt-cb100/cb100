# Teórica 04

**¿Por qué acceder por índice es O(1) en el vector y O(n) en la lista enlazada?**

El vector tiene **acceso directo**: `datos[i]` calcula la dirección de la celda i al instante. La lista enlazada no guarda las celdas contiguas: para llegar a la posición i hay que **recorrer** nodo por nodo desde el primero.
