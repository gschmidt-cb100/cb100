# Teórica 08

**¿Qué relaciones se representan en un diagrama UML de clases?**

Principalmente: **herencia** (triángulo con línea llena, `extends`), **implementación** (triángulo con línea punteada, `implements`) y **asociación** (flecha, "usa/tiene"). Además, cada clase muestra sus campos y métodos con su **visibilidad** (`+` público, `-` privado, `#` protegido).
