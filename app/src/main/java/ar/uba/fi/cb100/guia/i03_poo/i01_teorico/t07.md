# Teórica 07

**¿Para qué sirven los genéricos? Dá un ejemplo.**

Permiten escribir clases y métodos que funcionan con **cualquier tipo** manteniendo seguridad de tipos en compilación. Ejemplo: `Caja<T>` guarda un valor de tipo `T` decidido al usarla (`new Caja<String>("hola")`); son la base de las estructuras de datos reutilizables.
