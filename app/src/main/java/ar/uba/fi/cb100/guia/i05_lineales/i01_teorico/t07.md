# Teórica 07

**¿Qué caracteriza al TDA Conjunto? ¿Por qué `agregar` es O(n) en una implementación sobre lista?**

El **Conjunto** no admite duplicados y no tiene posición: sólo importa si un elemento está o no. Sobre una lista, `agregar` primero debe **chequear** si el elemento ya está (recorriendo la lista), y eso es O(n). Con una tabla de hash sería O(1) promedio.
