# Teórica 10

**¿Qué ventaja aporta JUnit frente a probar con `System.out.println`?**

Los tests con JUnit son **automáticos y repetibles**: verifican solos el resultado (verde/rojo), se corren todos con un comando, detectan al instante regresiones y documentan cómo se espera que funcione el código. Con `println` hay que mirar y comparar a mano cada vez.
