# Teórica 03

**¿Por qué insertar en el medio de un vector es O(n) y en una lista enlazada (ubicado el lugar) es O(1)?**

En el vector hay que **correr** todos los elementos posteriores para hacer/tapar el hueco: O(n). En la lista enlazada sólo se **re-enganchan** un par de referencias: O(1) (aunque *llegar* a la posición sea O(n)).
