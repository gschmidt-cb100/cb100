# Teórica 04

**Diferenciá tipo primitivo y tipo por referencia. Dá un ejemplo.**

Un **primitivo** (`int`, `double`, `boolean`, `char`…) guarda el valor directamente: `int edad = 42;`. Un **tipo por referencia** (`String`, arreglos, tus clases) guarda una referencia que apunta a un objeto: `String nombre = "Ada";`. Copiar un primitivo copia el valor; copiar una referencia copia el "puntero" al mismo objeto.
