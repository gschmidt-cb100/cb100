# Teórica 07

**¿Para qué sirve un `enum`? ¿Qué ventaja tiene sobre usar cadenas?**

Define un tipo con un **conjunto fijo y conocido** de valores. Frente a usar cadenas o números mágicos, es más seguro: el compilador conoce todos los casos, evita valores inválidos y permite que el `switch` verifique que están todos cubiertos.
