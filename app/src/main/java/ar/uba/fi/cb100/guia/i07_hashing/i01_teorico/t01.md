# Teórica 01

**¿Qué es una función de hash y qué tres propiedades debe tener?**

Es una función que convierte una clave (de cualquier tipo) en un **entero**, que luego se lleva con el módulo al rango de índices de la tabla. Debe ser: (1) **determinista** — la misma clave produce siempre el mismo número, si no la clave guardada sería inhallable; (2) **uniforme** — reparte las claves de forma pareja entre las celdas, para que no se formen baldes sobrecargados; y (3) **rápida** — se calcula en $O(1)$ (u $O(largo)$ para cadenas), porque si calcular el hash fuera caro se perdería la gracia de la estructura.
