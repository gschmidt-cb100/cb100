# Teórica 05

**¿Cuándo usarías una interfaz y cuándo una clase abstracta?**

Una **interfaz** para declarar un contrato que muchas clases (aun sin relación) pueden cumplir; una clase implementa varias. Una **clase abstracta** cuando además querés compartir estado o código entre subclases emparentadas; se hereda de una sola.
