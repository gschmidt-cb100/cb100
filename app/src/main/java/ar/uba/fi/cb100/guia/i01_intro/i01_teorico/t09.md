# Teórica 09

**¿Por qué importa el orden de los bloques `catch`?**

Java evalúa los `catch` de arriba hacia abajo y usa el primero que corresponda. Si ponés una excepción **general** antes que una **específica**, la general captura todo y la específica queda inalcanzable: el código no compila. El orden va **de lo más específico a lo más general**.
