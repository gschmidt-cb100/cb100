# Teórica 06

**¿Para qué sirve una lista circular y qué cuidado hay que tener al recorrerla?**

El último nodo vuelve a apuntar al primero, formando un anillo; sirve para recorridos **en ronda** (turnos, round-robin). Cuidado: nunca se llega a `null`, así que hay que **contar** los elementos para no dar vueltas infinitas.
