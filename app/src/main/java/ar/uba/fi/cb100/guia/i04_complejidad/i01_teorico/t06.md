# Teórica 06

**Enunciá los tres casos del Teorema Maestro y dá un ejemplo de cada uno.**

Para T(n)=a·T(n/b)+f(n), comparando f(n) con n^(log_b a): **Caso 1** (f crece menos) → Θ(n^log_b a); ej. T(n)=8T(n/2)+n² → Θ(n³). **Caso 2** (empatan) → Θ(n^log_b a·log n); ej. T(n)=2T(n/2)+n → Θ(n log n). **Caso 3** (f crece más) → Θ(f(n)); ej. T(n)=2T(n/2)+n² → Θ(n²).
