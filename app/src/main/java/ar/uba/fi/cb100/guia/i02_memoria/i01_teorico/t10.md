# Teórica 10

**¿Cuándo el recolector de basura libera un objeto? ¿Qué es una fuga de memoria lógica?**

El GC libera un objeto cuando ya **no es alcanzable** por ninguna referencia viva del programa. Una **fuga de memoria lógica** ocurre cuando mantenés una referencia a algo que ya no usás (por ejemplo, en una estructura que nunca limpiás): el objeto sigue siendo alcanzable y por eso **no** se libera.
