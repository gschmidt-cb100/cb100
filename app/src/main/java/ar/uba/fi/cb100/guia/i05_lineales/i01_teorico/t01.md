# Teórica 01

**¿Qué diferencia hay entre el tamaño y la capacidad de un vector dinámico?**

El **tamaño** es cuántos elementos hay realmente guardados; la **capacidad** es cuántas celdas tiene el arreglo interno. Suele haber celdas libres (capacidad > tamaño) para poder agregar sin redimensionar cada vez.
