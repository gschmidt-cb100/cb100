# Teórica 06

**¿Por qué `equals` y `hashCode` deben ser consistentes?**

Porque muchas estructuras (sobre todo las tablas de hash) asumen el contrato: si dos objetos son iguales según `equals`, deben tener el mismo `hashCode`. Si se rompe, un objeto "desaparece" de una tabla de hash y aparecen errores muy difíciles de rastrear. Por eso, si redefinís uno, redefiní el otro.
