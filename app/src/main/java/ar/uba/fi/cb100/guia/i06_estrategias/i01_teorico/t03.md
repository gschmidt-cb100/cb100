# Teórica 03

**¿La JVM optimiza la recursión de cola (tail call)? ¿Qué implica esto para recursiones muy profundas?**

No. A diferencia de otros lenguajes (varios funcionales, o compiladores con *tail call optimization*), la JVM **no** convierte automáticamente una recursión de cola en un bucle, así que cada llamada sigue ocupando un marco en la pila aunque sea lo último que hace el método. En consecuencia, una recursión **muy profunda** (por ejemplo, recorrer linealmente millones de elementos recursivamente) puede desbordar la pila y lanzar `StackOverflowError`. Cuando la profundidad puede ser grande, conviene reescribir el algoritmo de forma **iterativa** (con un bucle y, si hace falta, una pila explícita).
