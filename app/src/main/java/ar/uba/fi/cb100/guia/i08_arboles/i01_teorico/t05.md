# Teórica 05

**¿Qué recorrido usarías para copiar un árbol y cuál para liberarlo? ¿Por qué?**

Para **copiar** (o serializar): **pre-orden** (nodo, izquierda, derecha). Al visitar cada padre **antes** que sus hijos, si se insertan los valores en ese orden en un ABB nuevo, cada nodo encuentra a su padre ya creado y cae exactamente en la misma posición: el árbol reconstruido es idéntico.

Para **liberar** (o para cualquier operación que necesite a los hijos resueltos antes que el padre, como evaluar un árbol de expresiones): **post-orden** (izquierda, derecha, nodo). Se procesan primero los hijos y al final el padre — nunca se destruye un nodo cuyos hijos todavía se necesitan. En Java el GC libera solo, pero el patrón sigue siendo el correcto para calcular de abajo hacia arriba (alturas, tamaños, expresiones).
