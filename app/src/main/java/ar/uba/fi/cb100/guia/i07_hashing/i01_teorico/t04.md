# Teórica 04

**Explicá el sondeo lineal. ¿Qué es el clustering primario?**

En el **direccionamiento abierto** todos los pares viven en el arreglo mismo, sin listas. Con **sondeo lineal**, si la celda que indica el hash está ocupada se prueba la siguiente ($i, i+1, i+2, \dots$, con vuelta circular) hasta encontrar una libre; buscar repite ese mismo recorrido hasta encontrar la clave o una celda vacía (que significa "no está").

El **clustering primario** es el defecto característico del sondeo lineal: se forman **racimos** de celdas ocupadas consecutivas. Cualquier clave cuyo hash caiga en cualquier punto del racimo termina agregándose **al final del racimo**, con lo que éste crece — y al crecer, capta aún más claves. Es un efecto que se **auto-alimenta** y degrada las operaciones; por eso el direccionamiento abierto exige factores de carga bajos (típicamente $\alpha \le 0.5$) y existen variantes como el sondeo cuadrático y el doble hashing.
