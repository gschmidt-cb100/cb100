# Teórica 02

**¿Qué diferencia hay entre el JDK, el JRE y la JVM?**

La **JVM** ejecuta el bytecode. El **JRE** es la JVM más las bibliotecas estándar: lo mínimo para *ejecutar*. El **JDK** es el JRE más las herramientas de *desarrollo* (`javac`, `javadoc`…): lo necesario para *escribir y compilar*. En resumen: JDK ⊃ JRE ⊃ JVM.
