# Teórica 06

**¿Qué es el aliasing y qué riesgo trae cuando el objeto es mutable?**

Aliasing es tener dos (o más) referencias apuntando al **mismo objeto**. Si el objeto es mutable, un cambio hecho a través de una referencia lo ven todas las demás, lo que puede producir efectos inesperados si no te das cuenta de que comparten el objeto.
