# Teórica 05

**Enumerá y explicá los tres pasos de la división y conquista.**

1. **Dividir**: partir el problema en dos o más subproblemas más chicos del **mismo tipo** que el original (por ejemplo, las dos mitades de un arreglo).
2. **Resolver** (conquistar): resolver cada subproblema **recursivamente**, hasta llegar a un caso base tan chico que se resuelve directo.
3. **Combinar**: unir las soluciones parciales para armar la solución del problema original (por ejemplo, fusionar dos mitades ordenadas en una sola ordenada).

El costo total se describe con una recurrencia $T(n) = a\,T(n/b) + f(n)$, donde $a$ es la cantidad de subproblemas, $n/b$ su tamaño y $f(n)$ el costo de dividir y combinar; se resuelve con el Teorema Maestro.
