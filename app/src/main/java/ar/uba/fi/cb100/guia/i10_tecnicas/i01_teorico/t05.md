# Teórica 05

**¿Qué son la subestructura óptima y los subproblemas superpuestos? ¿Por qué DP necesita ambas?**

**Subestructura óptima**: la solución óptima del problema se construye con soluciones óptimas de sus subproblemas (el mejor vuelto de $6 es una moneda más el mejor vuelto del resto). Sin esto, guardar resultados de subproblemas no sirve, porque el óptimo local no participa del global — la tabla daría números sin significado.

**Subproblemas superpuestos**: los mismos subproblemas aparecen repetidos en la recursión (el fib(3) que se calculaba dos veces). Esto es lo que hace **rentable** guardar los resultados: cada celda se calcula una vez y se reusa muchas.

Si hay subestructura pero los subproblemas no se repiten (las dos mitades de Mergesort son distintas), alcanza **división y conquista**: memoizar no ahorra nada. DP es exactamente la técnica para cuando se cumplen las dos.
